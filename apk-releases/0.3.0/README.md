# Kiekkopolku 0.3.0

[Lataa APK](https://github.com/Tenuxi/kiekkopolku/raw/refs/tags/v0.3.0/apk-releases/0.3.0/kiekkopolku-0.3.0-debug.apk)

Metrix-kierroshistorian tuonti tallennetulla pelaaja-ID:llä ja integraatiokoodilla. Sovelluksen avaaminen tarkistaa tiedot taustalla; latausilmaisin korvaa refresh-kuvakkeen. Historia säilyy offline-käyttöä varten. Manuaalinen päivitys tekee valituille pelaajille täyden uusintahaun.

VersionCode 3, vähintään Android 8.0. Sama debug-allekirjoitus kuin 0.1.0/0.2.0:ssa; asenna niiden päälle säilyttääksesi paikalliset tiedot. Lähdekoodi tagissa `v0.3.0`. SHA-256: `SHA256SUMS`.

40 testiä läpäisivät, lintissä ei virheitä. Mukana myös oikeasta julkisesta Metrix-tulosvastauksesta tehty sopimustesti. Omalla integraatiokoodilla haettavan historian kattavuus riippuu Metrixin käyttöoikeuksista. Puhelimen yksityisen historian loppukäyttötesti tehdään laitteessa.
