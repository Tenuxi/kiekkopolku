# Kiekkopolku 0.4.0

[Lataa APK](https://github.com/Tenuxi/kiekkopolku/raw/refs/tags/v0.4.0/apk-releases/0.4.0/kiekkopolku-0.4.0-debug.apk)

Tumma karttanäkymä pelatuille radoille, Metrix-ratakoordinaattien täydennys, viimeksi pelattu -oletusjärjestys ja koko historian / viimeisten 12 kuukauden tilastot. Metrix-tapahtumaluettelo säilytetään myös estetyille tuloskorteille; tapahtumatunnisteet erotetaan varmennetuista kierroksista.

VersionCode 4, Android 8.0 tai uudempi. Asenna nykyisen testisovelluksen päälle: sama debug-allekirjoitus säilyttää tiedot. Room-migraatiot säilyttävät profiilit, koodit ja historian. Tarkistussumma: `SHA256SUMS`. Lähdekoodi: tagi `v0.4.0`.

51 testiä läpäisi, lintissä ei virheitä. Natiivikartan laitetesti on vielä tehtävä puhelimessa. Taustakartta tarvitsee verkkoyhteyden tai aiemman SDK-välimuistin; sijaintilupaa ei pyydetä.
