# Kiekkopolku v0.1.0

Ensimmäinen paikallinen Android-testiversio (PHASE 2).

Sisältää pelaajaprofiilit, perheen yhteisen pelaajavalinnan, haettavan ja järjestettävän ratalistan, kierrokset ja väylätulokset, ace-listan sekä henkilökohtaiset ja yhteiset tilastot. Tiedot säilyvät laitteessa Room-tietokannassa. Esimerkkiperhe otetaan käyttöön erillisellä painikkeella, ja sen voi poistaa asetuksista.

Oikeiden Metrix-profiilien historiaa ei vielä haeta. Kartta ja ratatietojen rikastus tulevat myöhemmissä vaiheissa. Sovelluskuvake on väliaikainen Androidin oletuskuvake.

- Sovelluksen versio: **0.1.0**
- versionCode: **1**
- Paketti: `fi.kiekkopolku.app.debug`
- Android: **8.0 tai uudempi**
- Lähdekoodi: Git-tagi `v0.1.0`
- Testiallekirjoituksen SHA-256: `ed3447ca65cc0609705aea12962b6eb493bf7f8f03c52a2eb9711cec2a726dab`

Asennus ja vanhempien versioiden käyttö: [APK-arkiston ohje](../README.md). Fyysisen laitteen asennuskoe jää käyttäjän testattavaksi; kehitysympäristössä varmennetaan käännös, Robolectric-testit, lint ja APK:n allekirjoitus.
